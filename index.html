Generator wpisów do bazy

Dodajesz nową kartę za pomocą LLM? Wykorzystaj ten interfejs, aby wygenerować prawidłowy blok kodu JSON do doklejenia w pliku.

⚠️ Uwaga techniczna dotycząca przeglądarki (CORS):

Przeglądarki blokują asynchroniczne pobieranie zewnętrznych plików JSON, jeśli otwierasz plik HTML bezpośrednio z dysku twardego bez serwera lokalnego (protokół file://). Po wgraniu na GitHub Pages aplikacja ruszy automatycznie. Lokalnie uruchom ją np. poprzez rozszerzenie Live Server w VS Code.

Wzorcowy obiekt JSON dla LLM

Przekaż tę strukturę do modelu Gemini, aby kolejne książki były idealnie sformatowane i kompatybilne z tym frontendem:

{
  "id": 3,
  "archetype": "Pełna nazwa archetypu",
  "dane_bibliograficzne": {
    "tytul": "...", "autor": "...", "rok_wydania": 2026, "kraj_pochodzenia": "...", "gatunek": "..."
  },
  "o_czym_jest": "Streszczenie (200-400 słów)...",
  "dlaczego_byla_zakazywana": "...",
  "historia_cenzury": {
    "gdzie": "...", "kiedy": "...", "przez_kogo": "...", "jak_dlugo": "..."
  },
  "co_najbardziej_przestraszylo_cenzorow": "...",
  "wplyw_na_kulture": "...",
  "przeczytaj_takze": ["Tytuł 1", "Tytuł 2"],
  "ciekawostki": ["Ciekawostka 1", "Ciekawostka 2"],
  "ocena_wplywu": { "literacki": 5, "polityczny": 5, "filozoficzny": 5, "spoleczny": 5, "aktualnosc": 5 }
}
